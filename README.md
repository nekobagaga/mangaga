# mangaga 运行环境需求

## 必须环境

- Windows 10/11。
- Windows PowerShell 5.1。
- .NET Framework / WPF 运行环境，需能加载 `PresentationFramework`、`PresentationCore`、`WindowsBase`、`System.Windows.Forms`。
- Python 3.10 或更高版本，建议 Python 3.12。
- Python 包：`Pillow`。

## 压缩包支持

- `.zip`：使用 Python 标准库，无额外工具。
- `.rar` / `.7z`：建议安装 7-Zip，并确保可执行文件为以下任一形式：
  - `7z.exe`
  - `7zz.exe`
  - `7za.exe`
- 如果未安装 7-Zip，程序会尝试使用 Windows 自带 `tar.exe`，但兼容性不如 7-Zip。

## 可选 OCR 功能

作品名识别需要额外安装：

- `paddleocr`
- `paddlepaddle`
- `manga-ocr`
- `torch`
- `transformers`

OCR 模型文件不随本工具发布。首次使用时由用户自行在软件提示的初始化流程中允许 PaddleOCR 下载并缓存模型。
软件会在首次手动开始作品名识别时检查 OCR 状态，并把用户选择保存到 `data/settings.json`。

## 可选联网 Tag 功能

自动 Tag 识别会访问用户主动配置或触发的站点，例如 EH/ExHentai、WNACG。

- 基础 HTTP 请求使用 Python 标准库 `urllib`。
- EH/ExHentai Cookie 不应写入源码仓库。
- EhTagTranslation 翻译库不随纯净版内置。首次使用 Tag 翻译时，用户可选择下载到 `data/ehtag-translation/db.text.json`、使用在线翻译或不翻译。
- Tag 翻译选择写入 `data/settings.json`。

# mangaga 操作说明

## 启动

- 双击 `Start-mangaga.cmd`。


## 主界面

- 拖拽文件夹、`.zip/.rar/.7z` 到窗口：添加漫画。
- 点击书架最后的 `+` 封面：添加压缩包或文件夹。
- 双击漫画封面：打开阅读器。
- 鼠标悬停漫画封面：显示该漫画所属分类。
- 封面右下角：显示总页数。
- 左侧分类：点击切换分类。
- 排序下拉：支持名称、页数、添加时间。
- 重复项分类默认按名称排序。

## 选择与批量操作

- 单击漫画：选中。
- `Ctrl + 单击`：追加或取消单本选择。
- `Shift + 单击`：范围选择。
- 按住鼠标左键拖动：框选多本。
- `Ctrl + A`：全选当前分类。
- `Esc`：取消选择。
- 点击主界面空白处：取消选择。
- `Delete`：从书架移除选中漫画。

从书架移除只会移除软件记录和缓存，不会删除本地原文件。

## 主界面右键菜单

在漫画上右键：

- 从书架移除
- 打开原文件位置，单选时可用
- 自动识别Tag
- 一键查重
- 设置分类
- 移出重复项，仅在重复项分类中显示

在主界面空白处右键：

- 全选
- 取消选择
- 查重当前分类

## 分类

系统分类：

- 全部
- 未分类
- 喜爱
- 识别中
- 待确认
- 需要密码
- tag未找到
- 重复项

说明：

- 喜爱、识别中、待确认、需要密码、tag未找到、重复项不可删除。
- 识别中、待确认、需要密码、重复项不显示添加用的 `+`。
- 自定义分类可通过左侧 `+ 新建分类` 创建。
- 左侧每个分类会显示当前分类内作品数量。

左侧自定义分类右键：

- 重命名分类
- 加入黑名单
- 删除分类

左侧自定义分类拖拽：

- 将一个自定义分类拖到另一个自定义分类上：合并分类。
- 合并后源分类消失，作品进入目标分类。
- 以后再次识别到源 tag，会自动归到目标分类。

## 分类管理

点击左侧顶部 `分类管理` 打开管理窗口。

支持操作：

- 分类以文件夹图标排列。
- 单选、多选、`Ctrl + A` 全选。
- `Esc` 取消选择。
- 点击空白处取消选择。
- 可选择按创建顺序或分类名字排序。

空白处右键：

- 全选
- 取消选择
- 清理空分类

分类右键：

- 重命名
- 合并到
- 加入黑名单
- 删除
- 属性

拖拽合并：

- 在分类管理窗口中，将一个或多个分类拖到另一个分类上即可合并。
- 关闭分类管理窗口时会统一确认并执行修改。

## Tag 管理

点击左侧顶部 `Tag管理` 打开。

支持操作：

- 查看原始 tag、来源、目标分类、作品数、作品示例。
- 将未映射 tag 映射到分类。
- 将 tag 加入黑名单。
- 保留为自定义分类。
- 刷新列表。

自动识别 Tag 首次使用时，如果没有 EhTagTranslation 翻译库，会弹出三种选择：

- 下载 EhTagTranslation 翻译库
- 使用在线翻译
- 不翻译

选择会写入 `data/settings.json`，后续不会反复弹出。

## 作品名 OCR

以下作品名会进入 `识别中`：

- 空名字
- 明显乱码
- 长十六进制哈希名
- 纯编号名，例如 `001`、`第001话`、`ch01`、`vol01`

在 `识别中` 分类底部：

- 点击 `开始识别`：后台按顺序 OCR。
- 点击 `暂停识别`：暂停识别队列。

识别流程：

- 抽取前 5 页与后 5 页。
- 使用本机 PaddleOCR 识别图片文字。
- 识别完成后进入 `待确认`。
- 如果识别到候选作品名，会自动采用第一候选作为显示名。

在 `待确认` 分类中：

- 封面左上角会显示 `未选择`、`已选择` 或 `已分类` 按钮。
- 点击按钮可选择候选作品名。
- 选择作品名后会自动尝试识别 Tag。
- Tag 成功后按钮显示为 `已分类`。

## 自动 Tag

触发方式：

- 选中漫画后右键 `自动识别Tag`。
- 在 `待确认` 中选择候选作品名后会自动触发。

识别规则：

- 会先按同人常见命名格式解析作品名。
- 优先搜索 EH/ExHentai。
- EH/ExHentai 未匹配时，兜底搜索 WNACG。
- 队列单线程执行。
- 同一站点请求之间使用 3000ms 到 5000ms 的随机等待时间。

识别结果：

- 识别到的重点 tag 会自动创建或复用用户分类。
- EH/ExHentai 的英文 tag 会按设置翻译成中文分类名。
- WNACG 的中文 tag 会进行繁简、别名和已知映射归一。
- 没找到 tag 的作品会进入 `tag未找到`。
- 用户手动给 `tag未找到` 中的作品添加分类后，会自动从 `tag未找到` 移出。

## 查重

触发方式：

- 选中漫画后右键 `一键查重`。
- 主界面空白处右键 `查重当前分类`。

说明：

- 查重全程本地执行。
- 后台单线程运行，不会联网。
- 完全重复资源会进入 `重复项`。
- 同作品不同版本会合并为一个作品条目。
- 封面一致但判断为不同作品时，会作为连载或同系列条目合并。

在 `重复项` 分类中：

- 可手动移除多余重复项。
- 当只剩下一个时，可右键 `移出重复项`。

## 加密压缩包

- 添加时遇到加密文件：不会卡住，会进入 `需要密码`。
- 状态栏会显示 `需要密码：xxx`。
- 打开需要密码的漫画时会弹出密码输入框。
- 输入一次密码后会自动保存。
- 成功打开后会自动补生成封面。

## 阅读器

打开方式：

- 双击漫画封面。
- 如果漫画有多个版本，会先进入版本选择窗口。

按钮：

- 上一页
- 下一页
- 首页
- 喜爱
- 自动播放
- 自动播放间隔 `- / +`

快捷键：

- `Right` / `Down` / `PageDown` / `Space`：下一页。
- `Left` / `Up` / `PageUp`：上一页。
- `Home`：跳到第一页。
- `F`：加入或移出喜爱。
- `Esc`：关闭阅读器。

鼠标：

- 鼠标滚轮：放大或缩小图片。
- 当前阅读窗口内切换页面会保留缩放倍率。
- 关闭阅读器再打开会恢复默认倍率。
- 鼠标静止 3 秒后，除图片外的按钮和顶部栏会自动隐藏。
- 移动鼠标后按钮和顶部栏重新显示。

翻页循环：

- 最后一页继续下一页：回到第一页。
- 第一页继续上一页：跳到最后一页。

自动播放：

- 点击播放按钮开始或暂停。
- 间隔可用 `- / +` 每次调整 1 秒。
- 也可直接输入秒数。
- 间隔精确到 0.1 秒。

## 状态栏

右侧状态栏会实时显示后台任务，例如：

- 添加漫画
- 生成封面
- 需要密码
- OCR 识别
- 自动 Tag
- 查重
- 移除书架项目

状态栏内容只保留本次软件运行期间的信息，关闭软件后不会保留。

## 数据与缓存

- 书架数据：`data/library.json`
- 设置数据：`data/settings.json`
- 封面缓存：`data/covers`
- 阅读临时缓存：`data/session-cache`
- OCR 缓存：`data/paddle-user`
- EhTagTranslation 翻译库：`data/ehtag-translation/db.text.json`

说明：

- `data/session-cache` 会在软件启动时清理上次残留。
- 关闭软件时会清理本次阅读缓存。
- 从书架移除不会删除本地原文件。
